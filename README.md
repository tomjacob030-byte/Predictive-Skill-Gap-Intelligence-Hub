# Predictive Skill Gap Intelligence Hub

## Overview

Predictive Skill Gap Intelligence Hub is a workforce intelligence platform developed using Python and Streamlit. The system predicts future workforce demand and supply trends, identifies skill gaps, analyzes regional opportunities, and supports policy-based decision making through interactive visualizations.

## Features

- Workforce Demand and Supply Forecasting
- Skill Gap Analysis
- Regional Opportunity Hotspot Identification
- Policy Impact Simulation
- Economic Risk Assessment
- Interactive Dashboards and Visualizations
- Competency Gap Analysis

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## Project Structure

- app.py - Main application file
- requirements.txt - Required Python packages
- Project_Report.pdf - Project documentation
- README.md - Project information

## Installation

1. Install Python 3.10 or above.
2. Install required packages:

pip install -r requirements.txt

3. Run the application:

streamlit run app.py

## How to Use

1. Enter a focus domain.
2. Configure research parameters.
3. Run the simulation.
4. View forecasts and analytics.
5. Analyze skill gaps and regional opportunities.
6. Compare policy intervention scenarios.
